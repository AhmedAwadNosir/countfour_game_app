# 🎮 Count Four Game

Count Four Game is a classic connect-four style game where two players take turns dropping tokens, aiming to connect four in a row — horizontally, vertically, or diagonally — to win.

---

## 🚀 Features

### 🎯 Gameplay
- Two-player interactive game  
- Turn-based gameplay system  
- Real-time board updates  

### 🧠 Game Logic
- Automatic win detection (horizontal, vertical, diagonal)  
- Draw detection when board is full  
- Game reset and replay functionality  
 
---

## 🛠️ Technologies

- **Flutter & Dart**

### 🧩 State Management
- **GetX** for efficient and reactive state management
